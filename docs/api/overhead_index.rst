Simulator API Reference
=======================

The module reference for ``fyst_trajectories.overhead``, the offline
observing-night simulator: the timeline model, the two planners
(``generate_timeline`` and ``plan_calibration_night``), the scheduler
internals behind the first of them, trajectory reconstruction, and the
ECSV format. Task-oriented walkthroughs start at
:doc:`../overhead_quickstart`.
